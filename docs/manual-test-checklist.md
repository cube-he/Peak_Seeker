## 测试账号准备

在开始前，通过浏览器 F12 Console 注册三个角色的账号：

```js
// 老师
fetch('/api/v1/auth/register', {method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({username:'test_teacher', password:'Teacher1', role:'TEACHER'})}).then(r=>r.json()).then(console.log)

// 管理员
fetch('/api/v1/auth/register', {method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({username:'test_admin', password:'Admin123', role:'ADMIN'})}).then(r=>r.json()).then(console.log)
```
