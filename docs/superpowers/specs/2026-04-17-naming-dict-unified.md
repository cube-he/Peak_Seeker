## 二、统一命名模板（提案）

```
{ID}_{年份}_{科类}_{大批次}[_{子类型}]_{数据类型}[_第{N}次][_{引擎}].xlsx
```

### 字段取值域

| 字段 | 取值 | 备注 |
|---|---|---|
| ID | 原网页序号，如 3284、4402 | **绝不变动**（来源锚点） |
| 年份 | 2023 / 2024 / 2025 | |
| 科类 | **2024 及之前**：`理科` / `文科` / `文理综合`<br>**2025 及之后**：`物理类` / `历史类` / `物历综合`<br>**无法判断**：`未分科` | 需要抽查 xlsx 内容确定 |
| 大批次 | **旧口径（2023-2024）**：本科提前批 / 本科一批 / 本科二批 / 专科提前批 / 专科批<br>**新口径（2025-）**：本科提前批次 / 本科批次 / 专科提前批次 / 专科批次 | 严格按该年权威字典 |
| 子类型 | 见下文「三、批次×子类型矩阵」 | 可选 |
| 数据类型 | `征集志愿` / `招生计划` / `单招招生计划` / `补充数据` | |
| 第 N 次 | `第一次` / `第二次` / `第三次` / `第四次` / `第二次A段第一次B段`（复合） | 仅 `征集志愿` 用 |
| 引擎 | `mimo-v2-omni` / `claude` / `多引擎` / `mimo-v2-omni_corrected` / `PaddleOCR-VL-1.5` | xlsx 才有 |

### 文件夹命名（去掉引擎字段）

```
{ID}_{年份}_{科类}_{大批次}[_{子类型}]_{数据类型}[_第{N}次]
```

## 五、配套 xlsx 命名规则

xlsx 文件名 = **文件夹新名 + `_{引擎}.xlsx`**

例：
- 文件夹：`4402_2025_物理类_本科批次_A段_国家专项_征集志愿_第一次`
- 文件内：
  - `4402_2025_物理类_本科批次_A段_国家专项_征集志愿_第一次_mimo-v2-omni.xlsx`
  - `4402_2025_物理类_本科批次_A段_国家专项_征集志愿_第一次_claude.xlsx`
  - `4402_2025_物理类_本科批次_A段_国家专项_征集志愿_第一次_mimo-v2-omni_corrected.xlsx`

**特例**：`supplementary_2025_PaddleOCR-VL-1.5.xlsx`（出现在部分 2024 文件夹内）
- 重命名为：`{父文件夹新名}_补充数据_PaddleOCR-VL-1.5.xlsx` 还是保留原名？需要你决策。
