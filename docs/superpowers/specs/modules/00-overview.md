# 智愿家 — 项目总览

> 版本：v2.0（模块化重构版）| 日期：2026-04-14 | 目标：2026年6月中旬上线

## 项目定位

C端产品 + 专家工具兼顾的高考志愿填报系统（四川省）。

- **管理员**：系统管理、数据导入、权限配置、全局监控
- **老师**：志愿填报顾问，为学生生成/编辑/审核完整志愿方案
- **学生**：查看老师方案、轻量自助推荐、浏览院校专业库

核心价值：将线下专家级志愿填报能力（v4.4 系统抽样算法）完整产品化。

## 技术选型

| 层 | 技术 | 说明 |
|---|------|------|
| 前端框架 | Next.js 14 App Router | Route Groups 三端隔离 |
| UI | Ant Design 5 + Tailwind CSS | 沿用"智愿家"品牌设计 |
| 状态 | Zustand(全局) + useReducer(方案编辑器) | 编辑器独立状态管理 |
| 后端框架 | NestJS 10 | — |
| 权限 | CASL + PoliciesGuard | 数据级权限 |
| ORM | Prisma 7 | Client Extensions 审计 |
| 数据库 | MySQL (MariaDB 适配器) | 复合索引 + 分步迁移 |
| 缓存 | Redis 7 | 备选池(7天) + 队列 + SSE |
| 队列 | Bull (BullMQ) | 方案生成 + 导出 |
| 通知 | SSE (@Sse) | 后期 AI 对话改 WebSocket |
| 导出 | exceljs | 后端队列生成 |
| OCR | Python FastAPI | 继续完善 |

## 开发排期

```

  W4: 推荐引擎核心(筛选→评分→抽样→去重) + 单元测试(选科100%)

  W6: 老师工作台(编辑器+看板+审核) + 批量导入 + 分享链接

阶段3 (5/26~6/8) 2周 — 学生端+管理端+收尾
  W7: 学生端 + 管理后台 + 参数调优 + 导出三格式
  W8: 集成测试 + 冒烟5链路 + 监控 + 上线

阶段4 (6/9~6/20) 缓冲 — bug修复 + 出分验证

冻结期 (6/20~7/5) — 仅hotfix

阶段5 (7月+) — AI模块 + 回测 + 参数优化
```

## 功能优先级

**P0（必须）**：三角色RBAC、数据导入、v4.4引擎、位次推导、同分决胜、出分批量重生成、老师全流程、学生查看、管理员管理

**P0-工程**：引擎单元测试、CI/CD、备份、健康检查

**P1（应该）**：多批次+提前批manual、方案版本+examSource、审核(行内)、征集分析、趋势+波动、2024数据折扣、评分可解释、免责+审计、敏感数据、SSE(含补发)、影响分析、轻量推荐、导出

**P1-工程**：集成测试+冒烟、Bull监控、慢请求日志、Redis降级、冻结协议

**P2（尽量）**：截图存档、录取追踪+评估、What-if、智能替换、统计面板、通俗解读、快捷操作、汇总表优化

**P3（后续）**：AI(分析+问答+推荐)、回测、AI采集+拍照、专业组变动检测、微信/短信
