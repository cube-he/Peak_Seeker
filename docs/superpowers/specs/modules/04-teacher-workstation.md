# 老师工作台

## 概述

老师的核心工作界面，覆盖从学生管理到方案交付的完整服务流程。桌面优先设计，查看/审核支持移动端。

## 数据模型引用

- StudentProfile, VolunteerPlan, PlanItem, PlanReview, PlanShareLink

## 页面结构

```
/teacher
  /dashboard              看板视图（按进度分列）
  /students
    /list                 学生列表（按标签筛选+搜索）
    /create               创建学生（代注册）
    /batch-import         批量导入（Excel上传→预览→确认）
    /[id]                 学生详情（渐进式表单，8组分步填写）
  /plans
    /list                 方案列表（按学生/批次/状态/examSource筛选）
    /generate/[studentId] 方案生成工作台 ★核心页面
    /[id]                 方案详情/编辑（双层展示+就地替换+撤销重做）
    /[id]/compare         方案对比（What-if / 跨examSource）
    /[id]/history         版本时序（diff对比）
    /[id]/export          导出预览（三种格式）
  /reviews
    /pending              待我审核（行内模式）
    /[id]                 审核工作台
  /browse                 院校/专业浏览
```

## Dashboard 看板

```
| 待采集(3) | 待生成(5) | 待审核(4) | 已定版(8) | 已填报(2) |
| 张三      | 李四      | 王五      | 赵六      | 钱七      |

每张卡片直接显示下一步操作按钮
支持按"紧急程度"排序
```

## 学生信息采集（渐进式）

```
Step 1: 核心信息（姓名+手机+选科+各科成绩）→ 2分钟，填完即可跑推荐
Step 2: 偏好/排除项 → 可以生成方案后再补
Step 3: 身体条件+经济+特殊条件 → 按需填
Step 4: 兴趣性格 → 随时补充

信息完整度进度条："当前65%——补充身体条件可排除受限专业"
UNDECIDED 字段标黄："⚠️ 是否接受民办：待确认"
```

## 批量导入学生

上传 Excel → 预览（绿=新建/黄=已存在/红=异常）→ 确认导入
提供标准模板下载
自动分配给当前老师，支持 tags 分组

## 方案生成工作台

```
左侧：学生信息卡片（可就地编辑）
中间：
  Step 1: 参数确认（系统自算+老师微调）
  Step 2: 批次选择（系统推荐+推荐理由）
  Step 3: 结果展示
    默认视图：精简卡片列表，梯度分色+锚点导航
    展开详情：24列+scoreBreakdown可视化+fullMajorRanking
    就地替换：点击→bin备选列表+智能Top3→点击即换+撤销
  Step 4: 审核与发布
右侧（可折叠）：备选池面板，按梯度tab+bin分区
```

## 方案编辑器状态管理

采用 useReducer + Context，独立于全局 Zustand。

```
状态：items + history(撤销栈) + future(重做栈) + historyLabels + isDirty + dataVersion
操作：REPLACE_ITEM | DELETE_ITEM | REORDER | ADD_FROM_POOL | UNDO | REDO | SAVE_SUCCESS | CONFLICT_DETECTED
历史栈：最多50步，每步带描述标签
快捷键：Ctrl+Z撤销 | Ctrl+Shift+Z重做 | Ctrl+S保存 | Ctrl+E导出
离开保护：isDirty → "有未保存的修改"
乐观锁冲突：收到409 → 显示差异 → 覆盖/放弃/合并
```

## 交叉审核（行内模式）

每个志愿项右侧：✅ / ❓ / ❌ 三按钮
❓和❌需填一句话说明
审核完成自动统计：52通过 / 2疑问 / 1建议替换
主管老师只关注标记项
支持多轮：驳回→修改→重新提交

## 快捷操作

- 学生列表每行：直达"生成方案"（选批次下拉）
- 键盘快捷键：Ctrl+S/E/Shift+R, ←/→导航, Enter展开, R替换, Delete删除
- 最近操作：顶部"最近"下拉（5个学生+5个方案）

## 导出三种格式

| 格式 | 用途 | 说明 |
|------|------|------|
| Excel完整版 | 老师工作用 | A3横版, 24列, 梯度分色, 多sheet备选池 |
| Excel精简版 | 家长打印用 | A4, 12列关键字段 |
| PDF打印版 | 家长打印用 | A4纵版, 灰度友好, 12pt+字号, 免责声明 |

## 方案分享链接

老师点"生成分享链接" → PlanShareLink(token, 7天有效) → 发给家长
家长打开 /share/{token} → 不需要登录 → 方案只读视图（含通俗解读）

## UX 要点

- 方案结果页信息密度高 → 双层展示（默认卡片+展开详情），不是直接铺24列表格
- 梯度锚点导航：侧边固定 高冲(13)|冲刺(11)|...|保底(6)，点击跳转
- 方案生成是异步的 → 需要进度提示和完成通知
- 出分后 Dashboard 显示"N个学生的方案需重新生成" + 一键批量操作

## 测试要点

- 编辑器撤销/重做完整性（50步不丢失）
- 乐观锁冲突检测
- 方案状态流转权限（普通老师不能跳过审核直接定版）
