# AI 功能规划（后期）

## 概述

全部要做，但优先级最低（P3）。先跑通规则算法，AI 作为增强层。

## 规划功能

### 1. 辅助分析

方案生成后，AI 对方案做个性化解读/风险报告。
- 输入：完整方案（PlanItem 列表）+ 学生信息
- 输出：文字化分析报告（整体风险评估、亮点、建议调整的志愿、专业前景解读）
- 展示位置：方案详情页"AI 分析"tab

### 2. 智能问答

学生/家长与 AI 对话咨询。
- "这个专业前景怎么样？"
- "我这个分数能上 XX 大学吗？"
- 技术：WebSocket 双向通信（此时 SSE 不够用）
- 上下文：学生信息 + 方案 + 院校/专业库

### 3. AI 参与推荐

LLM 评估专业前景、院校匹配度，作为评分的辅助维度。
- 不替代规则算法，而是作为额外的参考信号
- 例如：AI 判断某专业"AI 替代风险高" → 降低推荐度

### 4. AI 对话采集

通过对话方式采集学生信息，降低填表负担。
- "你对什么专业感兴趣？" → 提取偏好
- "你有色盲色弱吗？" → 提取身体条件
- 自然语言 → 结构化数据写入 StudentProfile

### 5. 拍照导入

线下信息拍照快速导入。
- 拍摄纸质成绩单 → OCR 识别 → 结构化 → 写入 StudentProfile
- 复用现有 OCR Service

## 技术依赖

- ai-config 模块已就绪（支持 Deepseek/OpenAI/Qwen 多供应商）
- 后端 ai 模块目前为空壳，预留了位置
- WebSocket 在 AI 对话时引入，其他通知继续用 SSE
