# 专家版主表 × 全国基础库 数据比对合并设计

## 概述

以 `03_专家版主表/output/` 为基底，用 `02_全国基础库/` 的权威数据补充字段、校验准确性，覆盖更新 output 目录产出可部署的生产数据。

## JOIN 策略

- **关联键：院校名称**（非院校代码，因专家版代码是自增序号1~2238）
- 29所因近期更名无法直接匹配的院校，建硬编码映射表处理（如华北科技学院→应急管理大学）
- 匹配率：院校库 98.7%、名录/章程/满意度 99.6%、学科评估 19.8%（仅覆盖461所有评估的院校）

## 产出文件

### 1. 院校信息表.xlsx（覆盖更新）

原表 2,238行/26列 → 约50列。

#### 修补字段

| 字段 | 操作 | 来源 | 说明 |
|------|------|------|------|
| 是否双一流 | 修补空值 | 全国高校完整名录 | 专家版漏标约60所（含清华北大），用名录的双一流标记补全 |

#### 新增字段（一对一，直接合入）

| 来源表 | 新增字段 | 补充说明 |
|--------|---------|---------|
| 院校满意度 | 综合满意度、生活满意度、环境满意度 | avgRank评分值 |
| 招生章程结构化 | 调档比例、专业分配规则、同分处理规则、体检限制、服从调剂说明 | 2025年章程提取 |
| 全国高校完整名录 | 阳光高考ID、官网、招生网址、招办电话 | 联系方式和桥接键 |
| 院校库_全国 | 升学率、建校年份、男女比例、QS排名、USNews排名、校友会排名 | 补充校情参考 |
| 学科评估（聚合） | 学科评估摘要 | 格式如"A+:3, A:5, B+:8"，从独立表聚合 |

#### 重叠字段处理策略

| 字段 | 决策 | 理由 |
|------|------|------|
| 省份/城市 | 保留专家版，不动 | 差异仅是格式（"大连"vs"大连市"） |
| 院校类型 | 保留专家版 | 支持多值标注（"综合 农林"），更细致 |
| 硕博士点 | 保留专家版原字段，不新增 | 口径不同但不并列避免混淆 |
| 保研率 | 保留专家版，**新增列**"保研率_基础库"作对照 | 数据年份/口径可能不同 |
| 排名 | 保留专家版综合排名，新增QS/USNews/校友会各体系排名 | 互补关系 |
| 转专业政策 | 两个都保留（原列=学生口碑，新增列=官方章程限制条款） | 来源不同，互补 |
| 办学性质 | 保留专家版 | 名录数据存在系统性错误（573所民办错标公办） |
| 隶属部门 | 保留专家版 | 各来源缩写体系不一致，统一成本高收益低 |

- 关联键：院校名称
- 字段：院校名称、学科代码、学科名称、评估等级、评估轮次

### 5. 冲突核查表.xlsx / 招生类型修正记录.xlsx（不变）

### 6. 校验报告（新文件）

输出到 `08_数据治理记录/基础库比对校验报告_2026-04-16.xlsx`

内容：
- Sheet1: 名称映射表（29所更名院校的新旧名称对应）
- Sheet2: 双一流修补记录（修补前后对比）
- Sheet3: 各字段匹配率统计（每个来源表的匹配行数/总行数/匹配率）
- Sheet4: 重叠字段差异明细（有冲突值的行清单）

## 技术实现

- 语言：Python (pandas + openpyxl)
- 脚本位置：`03_专家版主表/scripts/merge_base_library.py`
- 所有合并逻辑通过院校名称 left join（以专家版2,238行为基准，基础库多余的行不合入）
- 学科评估聚合：按院校名称 groupby，每个评估等级计数，拼接为摘要字符串

## 不做的事

- 不合入院校简介全文（大文本不适合表格）
- 不修改专业招生主表
- 不合入基础库中专家版已覆盖且更可信的字段（省份、城市、院校类型、办学性质、隶属部门）
- 不统一各来源的代码/缩写体系（投入产出比低）
