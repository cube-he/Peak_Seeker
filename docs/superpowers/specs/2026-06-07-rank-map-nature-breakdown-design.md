# 公办 vs 民办 录取位次分布图 — 设计

日期: 2026-06-07
页面: `/teacher/insights/rank-map`

## 目标

rank-map 页现有「各批次末档位次」图只给单一末位。老师需要看同一批次下**公办 / 民办**录取位次的整体差异，判断学生位次落在哪个性质区间（更可能进公办还是民办）。

## 关键数据发现（动手前已验证）

- 专业招生主表**没有办学性质列**；join 院校信息表（按 `院校代码`，行级 100% 命中）拿到 `办学性质`。
- **单看末位，公私几乎无差异**（批次最低录取那一档公私混排、共用同一地板）：物理本科批B段公办/民办末位都是 207063，专科批都是 284789。
- **差异在整个录取位次分布**：物理本科批B段公办组末位中位 89512、民办中位 188781（差一倍）。这才是有价值的对比。
- 民办只在 **本科批B段·普通类本科**（325 校）和 **高职(专科)批·普通类高职**（290 校）两个批次有量，其他批次基本全公办，无对比意义。

## 方案

口径 = **分布区间（箱线图）**，最全面：一图给出 最优/P25/中位/P75/末位 五点。放置 = 现有页底部**新增独立区块**，纯加法不动现有图。

### 数据管线 — `scripts/build_rank_map_json.py`

1. 额外读入 `院校信息表.xlsx`，取 `[院校代码, 办学性质]`，按 `院校代码` left join 主表。
2. 性质归一：含「公办/公立」→`公办`，含「民办/独立」→`民办`，其余（中外合作等）剔除。
3. 去重到专业组粒度（`院校代码 + 专业组代码 + 录取批次 + 科目`），仅取 `25专业组最低位次 > 0` 的行。
4. 按 `(录取批次, 招生类型, 性质)` 聚合：`组数 / 最优(min) / p25 / 中位 / p75 / 末位(max) / 计划(sum)`。
5. 只保留**公办与民办都 ≥ 10 组**的 `(批次, 类型)`（数据驱动，自然得到上述两个批次）。
6. 写入 JSON 新字段：
   ```
   natureBreakdown: {
     物理: [ { 批次, 招生类型, natures: { 公办: {组数,最优,p25,中位,p75,末位,计划}, 民办: {...} } }, ... ],
     历史: [ ... ]
   }
   ```

### 前端 — `rank-map/page.tsx`

- 读 `data.natureBreakdown[track]`，复用现有 `track` 切换与学生位次输入。
- 横向 ECharts `boxplot`：y 轴类目 = `批次·性质`，2 批次 × 2 性质 = 4 个盒子；公办蓝、民办橙。
- 学生位次 → 红色 `markLine` 竖线贯穿（复用现有图模式）。
- tooltip：5 分位 + 组数 + 计划。
- 一句解读说明：盒子 = 中间 50% 院校的录取位次区间，盒中竖线 = 中位，左右须 = 最优 / 末位。
