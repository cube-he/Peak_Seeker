## 执行中发现的问题

### ISSUE-007：batch_dict 错误诊断可定位性不足
- **发现时间**：2026-04-17（Task 3 code review）
- **影响阶段**：P2（跨源 normalize 时）
- **描述**：`normalize_batch_name` 当 `(year, course)` 组合不在 `_CANONICAL_NAMES` / `_ALIASES` 中时，统一抛 `未知批次`，掩盖了"字典本身缺该年份/科目"的根因
- **影响**：P2 跨源校验若传入未注册组合（如 `2023/理科`），报错信息误导
- **解决方案**：P2 开工前为 `normalize_batch_name` 增加"字典缺失"专用异常路径，并补测试用例
- **状态**：已登记，P2 前修复

### ISSUE-008：batch_dict 隐式"本科批→B段"默认映射
- **发现时间**：2026-04-17（Task 3 code review）
- **影响阶段**：P2
- **描述**：`_ALIASES[("2025","物理")]` 的 `"本科批": "本科批B段"` 基于假设"无段别时默认 B 段（主体最大）"。若某年/某数据源的"本科批"实际指 A 段或 A/B 合并，会被静默错误映射
- **影响**：P2 批次对齐可能产生跨年跨源的 silent drift
- **解决方案**：(a) 在 P2 首次出 conflict report 时按年份核对真实语义；(b) 若发现歧义，加 `strict=True` 参数禁用模糊默认 + 测试覆盖歧义别名
- **状态**：已登记，P2 首次跑 conflict report 时复核
