## 3. `field_fill` 字段分布（`both` 行中 03 缺值可由 01 补）

从 4,167 行 `field_fill` 候选样本观察到的典型模式：

- 03 通常保留 `最低分 / 最低位次 / 最高分 / 最高位次`
- 03 常见缺失字段：`平均分 / 平均位次`（03 整理时聚焦边界值）
- 01 有完整 min / avg / max 三元组 → 可定向补 `平均分 / 平均位次` 列

**预期入库规则（待用户批准）**：
- 允许 01 → 03 空字段写入的字段白名单：`平均分, 平均位次`（低风险）
- 需要人工确认的字段：`最低分, 平均分, 最高分, 最低位次, ...`（与已有 03 值比对后再写入）

## 5. 风险说明

1. **`new_rows` 不等于可直接入库**：7,362 行多为省属 / 高职 / 艺术类，需核验是否为四川实际招生院校；未桥接的 22 条国标可能是 01 端录入错误或院校已撤销。
2. **`field_fill` 需先验证 anomaly**：如果同一院校×专业×批次 的 `最低分 anomaly` 存在（557 非位次 anomaly 中约占一半），那么同行的"01 可补平均分"也可能不可信。入库规则应：**先过 anomaly 白名单，再做 field_fill**。
3. **位次口径待定**（ISSUE-014）：若确认为口径差异，`field_fill` 对位次字段的 01 值可能与 03 现有值不可比，不可混用。
